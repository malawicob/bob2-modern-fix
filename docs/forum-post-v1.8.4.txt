Version 1.8.4 is up, and it fixes something in 1.8.3 that could bite you.

If you are on a screen set above 100 per cent scaling, which most laptops
are these days, and you opened Install and repair and pressed the button
on the graphics translator row, it rewrote your dgVoodoo settings with
the wrong resolution and you got the enormous cockpit back. The cause is
a nice piece of Windows. It answers the question "what is the display
scaling" differently depending on whether the program asking is one that
understands scaling. Install and repair is a window, so it got one
answer, while the same code run from a console got the other. It read
100 per cent on a screen set to 150. Both readings now agree, whoever is
asking. If your cockpit came up huge after pressing Repair, that was
this, and this build puts it right.

The second fix came from 33lima, who found the DPI manifest step stuck in
a loop. It writes one setting that lives in the machine part of the
registry, Windows will not let an ordinary program write there without
asking permission first, and the window never asked. It tried, was
refused, wrote a line about it in the Details pane where nobody would
look, and then reported the job still needed doing. Press the button
again and the same thing happens again. It now asks properly: press Fix,
say Yes to the Windows prompt, and it is done. That row is also no longer
called "DPI manifest", which told you nothing. It is called Menu text
fix, because that is what it does.

He also asked, quite fairly, how he was meant to try the antialiasing on
its own when the only button turned it on together with ReShade. It now
has its own section in Settings, Graphics, with Off, 2x, 4x and 8x, and
4x marked as the one to use. Turn it on there, fly a mission, and you
know what it costs you before ReShade is anywhere near it.

Worth knowing while you are on that page: you probably do not want both.
Four of the five ReShade presets run their own antialiasing already, so
having the translator do it as well is paying twice for the same thing.
Subtle is the only preset without it, so Subtle plus 4x is the pairing
that makes sense. Otherwise pick a side. The page now says so.

Smaller things. The launcher shows your display size and the Windows
scaling, and what size the game is actually handed when those differ,
because almost every display problem in this game comes down to that one
number. The version line offers you the upgrade instead of just
mentioning it, so you can click it. And the launcher no longer stops you
with a dialog to announce a problem it has already fixed for you on the
way to a sortie: Windows puts one of its compatibility flags back on the
game most times it runs, that still gets removed, it just goes in a log
now instead of an OK button.

In the Squadron Room, the dispersal tells you when there is a morning
bulletin you have not read, with the day's headline on it, and takes you
there when you click it. The Log Book has stopped reporting an aircraft
name from the campaign save. The game defaults it to Silver Eagle, and
RAF fighters in 1940 simply were not known that way. They were known by
their squadron code and letter and their serial. Machines were pooled and
a man flew whatever was serviceable that morning, so he had no aeroplane
of his own to name. The names that were painted on were presentation
names, put there for whoever had donated the money, and had nothing to do
with the pilot.
