Twenty-five German pilot portraits, supplied by Patrick on 9 September
2026 and converted to the format the Room already uses for the RAF set:
280 x 420 JPEG, twenty to thirty kilobytes each.

They arrived at 1152 x 1728, which is the same 2:3 shape, so nothing had
to be cropped. The conversion crops to the exact ratio first anyway,
rather than scaling to fit, because squashing a face is worse than losing
a few pixels at an edge.

portraits.json beside this folder lists them, exactly as the RAF one
does. Get-Portraits reads whichever of the two the current side points
at, so nothing here needs naming differently.
